## 📌 Project Overview
**S.H.I.E.L.D.** transforms the often boring and stressful process of career planning into an engaging, cinematic, and data-driven experience. By taking a quick personality assessment (the "Avengers Aptitude Assessment"), users are assigned a Marvel superhero archetype. 

Using the lightning-fast **Groq LLaMA-3.3-70B AI**, the system instantly generates a highly classified, personalized **Mission Dossier**. This dossier includes a step-by-step career roadmap, salary expectations, required skills, and higher education paths for any selected career. Whether you're aiming to be a software engineer or a medical professional, S.H.I.E.L.D. gives you the intelligence to choose your path wisely.

## 🚀 Key Features
- **🦸‍♂️ Avengers Aptitude Assessment:** Answer 5 situational questions to discover your Marvel hero archetype (e.g., Iron Man, Doctor Strange, Black Panther).
- **🎬 Cinematic Hero Reveal:** Experience a visually stunning, suspense-filled reveal animation before accessing your career intelligence.
- **🤖 AI Mission Dossier:** Get a full career roadmap, critical skills, certifications, and threat assessments—generated by AI in under 2 seconds.
- **💳 The Infinity Earnings Scale:** Compare entry-level and senior salaries across major Indian tech and business hubs.
- **⚖️ Course Comparator:** Analyze two different career paths or degrees side-by-side to compare pros, cons, and ROI.
- **📱 Responsive, Native-Like UI:** A slick, dark-mode-first design featuring a bottom mobile app navigation bar for an optimal experience across all devices.

## 🛠️ Tech Stack
This project uses modern, scalable, and powerful technologies:
- **Frontend Framework:** [Next.js 14](https://nextjs.org/) (App Router, React)
- **Styling:** Vanilla CSS (CSS Variables, Flexbox/Grid, Responsive Design)
- **Icons:** [Lucide React](https://lucide.dev/)
- **AI Brain:** [Groq API](https://groq.com/) (Running *LLaMA-3.3-70B-Versatile* for lightning-fast responses)
- **Database & Auth:** MongoDB, Mongoose, JSON Web Tokens (JWT), and Bcrypt for secure user archiving.

## ⚙️ Setup and Installation

Follow these steps to run S.H.I.E.L.D. on your local machine:

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/techxastra.git
cd techxastra
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a file named `.env.local` in the root folder and add the following keys. You will need a MongoDB database and a free Groq API key.
```env
# Your MongoDB Connection String
MONGODB_URI="mongodb+srv://<username>:<password>@cluster.mongodb.net/shield"

# A secure random string for signing JWT tokens
JWT_SECRET="super_secret_jwt_string_here"

# Your Groq AI API Key
GROQ_API_KEY="gsk_your_groq_api_key_here"

# The local URL for development
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### 4. Start the application
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to start your mission.

## 📖 Usage Instructions
1. **Begin Your Mission:** Click "Begin Your Mission" on the landing page.
2. **Take the Quiz:** Answer the 5 quick questions. 
3. **Discover Your Archetype:** Watch the cinematic reveal.
4. **Generate a Dossier:** Search for a target career (e.g., "B.Tech Computer Science" or "Digital Marketing") and generate your AI-powered roadmap.
5. **Explore:** Use the bottom navigation bar (on mobile) or top navigation (on desktop) to check **Earnings** or **Compare** courses.
6. **Enlist (Optional):** Create an account to securely save and access your past Mission Dossiers at any time.

## ⚠️ Important Notes & Assumptions
- **AI Processing:** The application relies on the Groq API for rapid text generation. Ensure your API key is active. Sometimes, AI output format might slightly vary, but the prompt is strictly crafted to return JSON.
- **Database:** The users database uses custom JWT-based authentication perfectly designed for this project, avoiding heavy third-party auth services for faster load times.
- **Mobile First:** The application uses modern CSS. The navigation on mobile devices changes into an app-like bottom navigation bar to provide a sleek, thumb-friendly user experience.
